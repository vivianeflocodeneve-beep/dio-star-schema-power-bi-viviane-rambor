# Fonte dos dados

A base utilizada neste projeto segue a estrutura do **Financial Sample**, conjunto de dados de exemplo disponibilizado pela Microsoft para aprendizagem no Power BI.

A Microsoft mantém uma página oficial para download do Financial Sample e também permite carregar os dados de exemplo diretamente pelo Power BI Desktop.

Referência oficial:

https://learn.microsoft.com/en-us/power-bi/create-reports/sample-financial-download

Link direto indicado pela própria documentação Microsoft:

https://download.microsoft.com/download/1/4/E/14EDED28-6C58-4055-A65C-23B4DA81C4DE/Financial%20Sample.xlsx

## Observação

O arquivo `Financial Sample.xlsx` incluído neste pacote é uma base educacional compatível com a estrutura do Financial Sample, preparada para permitir a execução do projeto e da modelagem dimensional. Para uma entrega que exija especificamente o arquivo binário original da Microsoft, substitua-o pelo download oficial indicado acima.
