# Entrega do Desafio — DIO

## Criando um Star Schema para Cenários de Vendas com Power BI

**Autora:** Viviane Rambor  
**Repositório:** https://github.com/vivianeflocodeneve-beep/dio-star-schema-power-bi-viviane-rambor

Neste projeto desenvolvi um modelo dimensional em **Star Schema** utilizando o Microsoft Power BI para organizar um cenário de vendas. A estrutura foi construída com uma tabela fato central e dimensões relacionadas a calendário, produtos, detalhes dos produtos, descontos, segmento e país.

Durante o desenvolvimento trabalhei com conceitos de modelagem dimensional, relacionamentos, cardinalidade, Power Query e DAX. Também organizei o projeto para o GitHub, incluindo a base utilizada, documentação, medidas, imagens e o arquivo final do Power BI.

O principal aprendizado foi compreender, na prática, que a qualidade da análise começa pela modelagem dos dados. Um modelo bem estruturado facilita a criação de indicadores, melhora a leitura das informações e torna o desenvolvimento no Power BI mais consistente.
