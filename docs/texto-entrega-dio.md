# Texto sugerido para entrega na DIO

Neste projeto desenvolvi um modelo dimensional em Star Schema utilizando o Power BI.

A partir da base Financial Sample, organizei os dados em uma tabela fato central e tabelas dimensão, buscando deixar o modelo mais simples de analisar e preparado para criação de medidas e relatórios.

Durante o desenvolvimento trabalhei com Power Query, relacionamentos, cardinalidade, criação de tabela calendário e medidas DAX.

Também procurei organizar o repositório de forma clara, reunindo o modelo, documentação, imagens e códigos utilizados no projeto.

O principal aprendizado foi perceber que a qualidade de um relatório começa na modelagem dos dados. Quando a estrutura está bem organizada, as análises e os indicadores passam a ser construídos com muito mais segurança e clareza.
